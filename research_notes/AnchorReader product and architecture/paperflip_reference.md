# Paperflip player reference

Checked 10 October 2026. Source: [Paperflip commit 68c0ffa](https://github.com/chilliesdev/paperflip/tree/68c0ffa9b52d998b4cc0b0786c445567962b0bb7). Read source with GitHub CLI. Did not install, run, or test the app. Did not inspect video pixels or verify video rights. No code changed.

The user's requirement is clear: AnchorReader must show a real background video while narration reads the visible transcript. Paperflip supplies this interaction model. The core screen needs three layers: looping video, readable transcript, and playback/navigation controls. It does not need an exported video file for each lesson.

| Area | Verified Paperflip behavior | AnchorReader decision |
|---|---|---|
| Background | HTML video fills the screen with `object-cover`, loops, and plays inline. A gradient and dark text panel sit above it. Playback runs only for an active, playing slide. [Video layer](https://github.com/chilliesdev/paperflip/blob/68c0ffa9b52d998b4cc0b0786c445567962b0bb7/apps/web/src/lib/components/FeedSlide.svelte#L171-L219), [play control](https://github.com/chilliesdev/paperflip/blob/68c0ffa9b52d998b4cc0b0786c445567962b0bb7/apps/web/src/lib/components/FeedSlide.svelte#L24-L42). | Use one small cached MP4 loop as the core background. Keep it silent. Pause it with narration; offer reduced motion. |
| Transcript | Shows the current sentence. Words have source character offsets. The current word changes color, weight, and scale; past words remain visible. [Sentence selection](https://github.com/chilliesdev/paperflip/blob/68c0ffa9b52d998b4cc0b0786c445567962b0bb7/apps/web/src/lib/components/FeedSlide.svelte#L44-L104), [word display](https://github.com/chilliesdev/paperflip/blob/68c0ffa9b52d998b4cc0b0786c445567962b0bb7/apps/web/src/lib/components/FeedSlide.svelte#L144-L219). | Timed phrase/sentence overlay is core. Word highlighting is optional for the three-day build. Keep a full transcript view. |
| Speech timing | Browser `SpeechSynthesisUtterance` reads English text. Word boundary events provide character positions. The code sets `en-US`; it does not choose a specific voice. [Speech implementation](https://github.com/chilliesdev/paperflip/blob/68c0ffa9b52d998b4cc0b0786c445567962b0bb7/apps/web/src/lib/audio.ts#L62-L123). If no boundary arrives in 1.5 seconds, the feed switches to sentence-by-sentence dictation. [Fallback](https://github.com/chilliesdev/paperflip/blob/68c0ffa9b52d998b4cc0b0786c445567962b0bb7/apps/web/src/lib/components/Feed.svelte#L166-L265). | For the selected recorded-audio demo, use the audio playback time as the clock. Store reviewed cue start/end times. Browser speech boundary events are a separate implementation path; they cannot time prerecorded audio. |
| Navigation | Vertical Swiper displays one slide. Tap toggles speech; double tap changes the background. Optional auto-scroll moves to the next slide after speech. Pause, completion, and exit save progress. [Tap controls](https://github.com/chilliesdev/paperflip/blob/68c0ffa9b52d998b4cc0b0786c445567962b0bb7/apps/web/src/lib/components/Feed.svelte#L50-L70), [completion](https://github.com/chilliesdev/paperflip/blob/68c0ffa9b52d998b4cc0b0786c445567962b0bb7/apps/web/src/lib/components/Feed.svelte#L187-L205), [playback](https://github.com/chilliesdev/paperflip/blob/68c0ffa9b52d998b4cc0b0786c445567962b0bb7/apps/web/src/lib/components/Feed.svelte#L268-L301), [feed](https://github.com/chilliesdev/paperflip/blob/68c0ffa9b52d998b4cc0b0786c445567962b0bb7/apps/web/src/lib/components/Feed.svelte#L335-L378). | Retain vertical concept navigation, visible play/pause, replay, and resume. Stop for the recall check at a concept boundary. Swipe must not be the only control. |
| Assets/cache | Two configured MP4s, named Nebula and Forest, use public Supabase URLs. The layout loads the selected clip from Cache Storage or fetches it, creates a blob URL, then deletes other video cache entries. On load failure it falls back to the remote URL. [Asset list](https://github.com/chilliesdev/paperflip/blob/68c0ffa9b52d998b4cc0b0786c445567962b0bb7/packages/core/src/constants.ts#L6-L19), [loader](https://github.com/chilliesdev/paperflip/blob/68c0ffa9b52d998b4cc0b0786c445567962b0bb7/apps/web/src/routes/%2Blayout.svelte#L51-L108), [cache](https://github.com/chilliesdev/paperflip/blob/68c0ffa9b52d998b4cc0b0786c445567962b0bb7/apps/web/src/lib/stores/assets.ts#L5-L44). | Package an owned/licensed clip with AnchorReader's download. Verify all required assets before showing “Ready offline.” In offline mode, use a still fallback when a clip is absent; do not depend on a remote retry. |
| Chunking | Splits paragraphs, then sentences, to a default 1,000-character cap. An overlong sentence can split at a word boundary. This is a text-length rule. [Segmenter](https://github.com/chilliesdev/paperflip/blob/68c0ffa9b52d998b4cc0b0786c445567962b0bb7/packages/core/src/segmenter.ts#L5-L105). | Keep AnchorReader's concept boundaries. Display cues may change within a concept; a cue change must not create a new lesson or quiz. |
| Native screen | React Native uses `expo-video`, looped playback, active-slide pause/play, the same sentence/word presentation, and a progress bar. The current mobile bar has no scrubbing. [Video setup](https://github.com/chilliesdev/paperflip/blob/68c0ffa9b52d998b4cc0b0786c445567962b0bb7/apps/mobile/src/components/feed/FeedSlide.tsx#L21-L50), [render](https://github.com/chilliesdev/paperflip/blob/68c0ffa9b52d998b4cc0b0786c445567962b0bb7/apps/mobile/src/components/feed/FeedSlide.tsx#L160-L199). | Android remains optional. The same visual pattern fits the selected React PWA. No framework change is required to meet this requirement. |

The background has no semantic clock: it loops while the narration advances. Only narration and transcript need close timing. AnchorReader's source figure can cover and dim this background when a diagram is relevant. Quizzes then stop narration. These are AnchorReader additions; the inspected player files do not establish those features in Paperflip.

Three checks matter before reuse. First, verify playback and cue behavior on the actual phone. Source inspection does not prove browser speech works offline. Second, measure clip size and cache recovery. Paperflip's remote video fallback does not establish complete offline readiness. Third, use cleared media. The README describes local video files, while the inspected constants point to remote MP4s; use the source behavior as this reference. [README media instructions](https://github.com/chilliesdev/paperflip/blob/68c0ffa9b52d998b4cc0b0786c445567962b0bb7/README.md#L66-L74).
